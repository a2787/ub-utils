# OmniBlock v0.46.0

候选日期：2026-08-30；审计修订：2026-09-04
发布状态：本地候选；未创建 `v0.46.0` tag，未推送，未创建 GitHub Release。

## 用户可见变化

- 设置页“备份”区域新增主名单容量状态，显示人物数、身份数和序列化体积；名单达到软预警区间时给出分级提示，
  但不设置新的硬性人数上限，也不自动删除用户数据。
- 详细日志仍逐条保留用户动作、屏蔽/恢复和错误；被动 DOM/扫描事件继续按窗口聚合。日志状态现在还能报告分片写入次数、
  序列化字符量和 flush 耗时，便于区分“页面在忙”与“日志自身在忙”。
- 页面隐藏或冻结时暂停非必要扫描，恢复后只补一次同步；普通页面销毁时统一停止扫描器、观察器、订阅、timer 和 rAF，
  BFCache 暂存则保留可恢复会话。
- 屏蔽始终使用同一运行路径；必要事件记录持续工作，详细诊断明细仍由设置页已有日志开关控制，不新增“第一资源模式”或独立“诊断模式”。
- 抖音等高频页面的新增子树不再在 MutationObserver 回调中同步深遍历，而是进入下一帧队列；每帧最多处理 32 个根且使用
  8ms 时间预算。浅弹幕节点可以合并处理，复杂子树会自动续到下一帧。
- B站作者、微博作者、快速菜单、作品入口和评论批量入口由平台活动信号触发一次性防抖任务；请求处理完即停止计时，
  不再让无事可做的入口循环持续唤醒页面。SPA 路由变化由主扫描器统一广播。

## 开发运行时与安全边界

- 持久 MV3 开发扩展把 userscript 与主世界桥接封装在同一个词法作用域，`GM_getValue`、`GM_setValue`、跨域请求等能力
  不再暴露为页面可调用的 `window.GM_*`。
- 主世界与隔离世界消息使用每次构建随机生成的 HMAC-SHA256 密钥、来源标识和单调序列；未签名、重放或乱序消息被拒绝。
- 扩展存储仅允许 OmniBlock 主名单、备份和日志键；跨域只读请求仅允许脚本更新地址与 B站用户卡片查询，限制为 GET、
  无凭证、无自定义请求体/请求头，并设置超时和响应体上限。
- 隔离桥缺失时最多尝试 8 次并在约 4 秒内降级到 userscript 的本地默认路径，不再无限每 50ms 重试。

## 2026-09-04 审计后修复

- 启动运行锁移动到异步扩展存储恢复栅栏之前，避免同一文档在 `starting` 阶段重复创建扫描器、观察器和 UI。
- 主名单写入失败现在返回明确失败结果，保留本页内存状态但抑制备份/provider 的成功后置流程；设置页显示“未确认落盘”提示。
- 单日日志达到上限时一次性裁剪最近事件；抖音自动弹幕规则匹配和通用屏蔽判定各自只做一次，减少热路径重复计算。
- 名单身份查找增加惰性 key→人物索引，批量导入/作品级批量屏蔽避免重复遍历全部人物；外部标签页变化在本地存在未确认写入时报告冲突并保留当前内存状态。
- 评论管理器和楼中楼读取增加页面/面板 generation 与 AbortController 边界；关闭面板、SPA 路由切换或节点回收后，旧异步结果只安全丢弃，不重新渲染或提交名单。
- 贴吧现代详情评论增加已在登录态真站捕获的 `.pb-comment-item` + Vue `userInfo.id` 数字身份路径；首页 `.thread-card` 与不透明 portrait 参数仍不纳入支持。
- 微博详情虚拟评论在快速滚动触发物理行重排时，按当前 `translateY` 的空间顺序累计多条隐藏行的补位，避免按临时 DOM 顺序计算造成短暂重叠/空白；遇到超大或无效基线仍沿用原异常修复路径，用户主页嵌套评论不变。
- B站真实探针在评论管理器开闭可能回收 renderer 时重新获取仍连接的目标，并对楼回复确认框使用有界等待，避免把平台节点复用误报为脚本失败。
- 构建标识更新为 `0.46.0-signed-session-index-conflict-tieba-vue`；@version 仍为 0.46.0，本地候选仍未发布。

## 维护系统变化

- `docs/maintenance/PLAN.md` 成为唯一活动计划，`docs/architecture/ARCHITECTURE.md` 保存稳定运行时边界，重大选择由 ADR 记录。
- 文档门禁检查计划 ID、状态、依赖、验收证据、活动文档字节预算、CURRENT 源码快照祖先关系和候选源码 SHA-256。
- 当前任务没有修改 CI/CD 配置：项目红线要求此类修改单独授权，因此只完善本地可复现门禁，不静默新增工作流。

### `blocked`

- 抖音公开入口若仍停在验证码中间页，只能记录为 `blocked`，不能用人工性能夹具推导线上 CPU 数字。
- B站匿名页的统一评论管理器报告根评论分页读取失败；本轮只验证了当前 DOM、公开 API 契约和整楼操作闭环，
  没有把“全分页读取”写成真实站点通过。
- 微博维护自检公开页没有可安全观察的活动顶层虚拟列表 spacer，真实 spacer 基线仍记 `blocked`；详情页快速滚轮候选的活动内容补位已有上述登录态采样证据。
- 专用 Chrome 已在 `chrome://extensions` 刷新本地开发扩展；当前候选随后在 B站、抖音、微博、知乎和贴吧新页面完成无源码注入运行标记核对。
- `node test/maintenance-check.cjs` 的本地门禁、完整结构矩阵、B站隔离探针和微博回放通过，命令以退出码 2 汇总抖音验证码与微博顶层 spacer 两项 `blocked`，不是代码回归失败。
- X 本轮按用户要求不做登录态或功能验证；不是候选发布阻断项，只保留既有人工夹具证据。
