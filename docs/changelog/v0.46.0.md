# OmniBlock v0.46.0

候选日期：2026-08-30
发布状态：本地候选；未创建 `v0.46.0` tag，未推送，未创建 GitHub Release。

## 用户可见变化

- 设置页“备份”区域新增主名单容量状态，显示人物数、身份数和序列化体积；名单达到软预警区间时给出分级提示，
  但不设置新的硬性人数上限，也不自动删除用户数据。
- 详细日志仍逐条保留用户动作、屏蔽/恢复和错误；被动 DOM/扫描事件继续按窗口聚合。日志状态现在还能报告分片写入次数、
  序列化字符量和 flush 耗时，便于区分“页面在忙”与“日志自身在忙”。
- 页面隐藏或冻结时暂停非必要扫描，恢复后只补一次同步；普通页面销毁时统一停止扫描器、观察器、订阅、timer 和 rAF，
  BFCache 暂存则保留可恢复会话。
- 抖音等高频页面的新增子树不再在 MutationObserver 回调中同步深遍历，而是进入下一帧队列；每帧最多处理 32 个根且使用
  8ms 时间预算。浅弹幕节点可以合并处理，复杂子树会自动续到下一帧。
- B站作者、微博作者、快速菜单、作品入口和评论批量入口由平台活动信号触发一次性防抖任务；请求处理完即停止计时，
  不再让无事可做的入口循环持续唤醒页面。SPA 路由变化由主扫描器统一广播。

## 开发运行时与安全边界

- 持久 MV3 开发扩展把 userscript 与主世界桥接封装在同一个词法作用域，`GM_getValue`、`GM_setValue`、跨域请求等能力
  不再暴露为页面可调用的 `window.GM_*`。
- 主世界与隔离世界消息使用每次构建随机生成的 HMAC-SHA256 密钥、来源标识和单调序列；未签名、重放或乱序消息被拒绝。
- 扩展存储仅允许 OmniBlock 主名单、备份和日志键；跨域只读请求仅允许脚本更新地址与 B站用户卡片查询，限制为 GET、
  无凭证、无自定义请求体/请求头，并设置超时和响应体上限。
- 隔离桥缺失时最多尝试 8 次并在约 4 秒内降级到 userscript 的本地默认路径，不再无限每 50ms 重试。

## 维护系统变化

- `docs/maintenance/PLAN.md` 成为唯一活动计划，`docs/architecture/ARCHITECTURE.md` 保存稳定运行时边界，重大选择由 ADR 记录。
- 文档门禁检查计划 ID、状态、依赖、验收证据、活动文档字节预算、CURRENT 源码快照祖先关系和候选源码 SHA-256。
- 当前任务没有修改 CI/CD 配置：项目红线要求此类修改单独授权，因此只完善本地可复现门禁，不静默新增工作流。

## 验证边界

### `structure regression`

- 通用 UI/状态回归覆盖突发 DOM 分帧预算、名单容量状态、SPA 资源数量、freeze/resume、BFCache 与普通 pagehide 回收。
- 性能回归分别检查 Mutation、扫描、名单持久化和日志分片指标；微博回放同时检查虚拟列表布局同步耗时。
- 持久扩展回归覆盖三个新文档自动加载、跨页存储、页面伪造消息拒绝、`GM_*` 不泄露和 8 次有界降级。
- 最终完整命令、通过数量和真实探针结果以 [CURRENT.md](../maintenance/CURRENT.md) 的本轮事实为准。

### `real-site verified`

- 2026-08-30，隔离未登录 `bilibili.com/video/...` 页面注入当前源码：运行标记为 0.46.0；识别 2 条根评论、
  1 条子评论和 3 位作者；菜单本地入口、批量入口、Dock 折叠/悬停展开可见；单条完整线程零占位隐藏并撤销，
  同楼 3 位作者一次写入后全部撤销。
- 2026-08-30，隔离未登录 `weibo.com/...` 页面注入当前源码：识别 21 条评论和 21 位作者；一条楼中楼评论
  独立隐藏并撤销，正文和根评论保持可见。
- 以上只覆盖实际观察到的路径；0.45.0 的历史验收没有被自动升级为当前版本证据。

### `blocked`

- 抖音公开入口若仍停在验证码中间页，只能记录为 `blocked`，不能用人工性能夹具推导线上 CPU 数字。
- B站匿名页的统一评论管理器报告根评论分页读取失败；本轮只验证了当前 DOM、公开 API 契约和整楼操作闭环，
  没有把“全分页读取”写成真实站点通过。
- 微博本轮真实页没有可安全观察的活动顶层虚拟列表 spacer，真实补位路径仍记 `blocked`。
- 专用 Chrome 需要在 `chrome://extensions` 手动刷新本地开发扩展后，才能把无注入新页面结果归属于 0.46.0。
