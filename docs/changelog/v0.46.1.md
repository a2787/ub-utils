# OmniBlock v0.46.1

候选日期：2026-09-05
发布状态：本地候选；未 push、未创建 `v0.46.1` tag 或 GitHub Release。当前公开版本仍为
[`v0.46.0`](https://github.com/a2787/ub-utils/releases/tag/v0.46.0)。

## 用户可见变化

- 修复 B站视频评论三点菜单的本地入口回归：当真站评论菜单把举报项显示为「硬核会员举报」时，仍会插入「🚫 本地拉黑」；根评论仍保留「🧵 屏蔽该楼回复」。
- 入口按评论菜单所在的 `BILI-COMMENT-MENU` Shadow DOM 回到当前评论节点解析 `bili:uid`，不使用不可逆的弹幕 hash 冒充评论 UID。
- B站播放器浮动弹幕的「举报」路径仍保持原安全边界：没有唯一、未过期的弹幕身份时不注入可执行本地入口。

## 实现与回归

- 根因是评论菜单和弹幕举报共用“举报”文案；旧逻辑先进入弹幕 `mid_hash` 分支，没有浮动弹幕上下文便提前返回，跳过了评论 UID 解析。候选只在确认不是 `BILI-COMMENT-MENU` 项时进入该弹幕分支。
- 人工合成夹具加入单独的「硬核会员举报」评论菜单；该断言在旧分支上会得到 0 个本地按钮，候选要求本地按钮、整楼按钮和 `bili:uid` 均存在。

### `blocked`

- 浏览器自动化安全策略阻止在当前用户 Chrome 中打开 `chrome://extensions` 刷新已安装脚本，因此未能在同一用户会话中装载 0.46.1 后重新观察菜单；修复候选没有被写入用户真实名单。候选源码已由隔离真站探针验证，用户安装 0.46.1 后需刷新 B站视频页。
- B站匿名页统一评论管理器的根评论分页仍可能显示“部分加载”；本补丁不扩大分页范围。
