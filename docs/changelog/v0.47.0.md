# OmniBlock v0.47.0

候选日期：2026-09-06
发布状态：本地候选，未 push、未创建 tag 或 GitHub Release；当前公开版本仍为
[`v0.46.2`](https://github.com/a2787/ub-utils/releases/tag/v0.46.2)。

## 用户可见变化

- 设置面板新增默认关闭的「启用 AI 智能屏蔽（按预设规则自动分析当前页）」；可保存自然语言预设规则，
  也可临时输入本页面附加规则并点击「分析本页」。第一阶段只处理 B 站当前页已经观察到的评论/弹幕，
  其他平台保留现有屏蔽能力，不宣称已接入 AI 采集。
- AI 命中结果先进入本地多选审核框。可靠身份候选默认勾选；没有可靠身份的内容只展示，不提供可执行屏蔽；
  只有用户确认后才复用现有名单写入链路，并提供本次写入的撤销入口。
- 只接受 `http://localhost`、`127.0.0.1` 或 `::1` 的本机 OpenAI 兼容网关。请求只包含规则、内容类型、临时项目编号和截断正文，
  不包含 UID、`mid`、弹幕 hash、作者主页、完整 URL、Cookie、本地名单或 API Key。
- provider 多配置、自动切换、重试、并发/速率限制、cooldown 和记忆不放进 userscript；优先由本地 LiteLLM Proxy 等成熟网关管理，
  OpenClaw 只有在实际提供窄 JSON 接口且不改动 V2 时才作为可选后端。候选代码不重复实现 provider router。
- 仓库附带 `gateway/` 配置向导、LiteLLM Docker Compose、健康检查和停止脚本；用户只需在向导中填写各 provider 的 URL、模型、Key 及可选额度，
  插件继续连接统一的 `omni-default` loopback 地址。模型名以 `deepseek-v4` 开头时，向导默认将 thinking mode 设为 `disabled`，
  通过 LiteLLM `extra_body` 关闭思考输出，以适配插件的 20 秒客户端请求边界。

## 实现边界

- AI 默认关闭；未启用时不发送页面文本。自动分析按当前 SPA 路由最多执行一次成功分析；评论/弹幕晚于首轮挂载时只做有界重试，
  不建立常驻轮询。路由、页面隐藏、运行时销毁或设置关闭时会取消计时器、请求和审核框。
- 采样上限为 80 条、单条 800 字符、总正文 48,000 字符；已可靠屏蔽身份不再发送给模型。模型只返回临时项目编号，未知编号和非 JSON 结果会被丢弃。
- 内容判断和身份归属分离。即使模型建议屏蔽，也不能把 `mid_hash`、一对多候选或无身份文本伪装成 UID；无可靠身份项目不会进入现有名单。
