# OmniBlock v0.57.4：撤销接管右键的本地拉黑菜单

日期：2026-09-13
状态：已公开发布（tag/Release：v0.57.4）

## 用户可见变化

- **右键完全交还页面**：删除"命中评论/帖子条目时接管右键并弹出自建菜单「🚫 拉黑此用户」"的整套实现。此前右键落在已捕获条目上会被 `preventDefault` 并替换为插件的拉黑按钮，使平台原生右键菜单（复制链接、在新标签页打开、平台的"不感兴趣"等）在这些位置失效；现在右键、平台原生菜单与页面自身的上下文操作全部保持原样。
- **本地拉黑入口不变**：平台原生菜单（三点或「更多」→「举报」「加入黑名单」）旁的「🚫 本地拉黑」、确认气泡、撤销 toast、B站弹幕工具、批量屏蔽与作品级屏蔽全部保留；右键不再是任何功能的入口。
- 快捷入口在身份无法识别时的提示不再引导用户"试右键"，改为"请重新打开菜单后重试"。

## 实现边界

- 删除范围：`document` 级 `contextmenu` 捕获监听、`buildContextMenu`、仅供该监听使用的 `findItem`（沿 `Event.composedPath` 命中条目）、`#ob-ctx` 样式与相关注释。`showConfirm`、`Store`、各平台适配器、身份键规范与隐藏链路均未改动。
- 不新增替代手势或新入口；不改动存储格式、同步服务、账户数据或平台写入边界。
- 本地拉黑仍然只写本地名单，绝不触发平台官方拉黑、举报、关注或发帖。
