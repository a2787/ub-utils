# OmniBlock v0.46.2

候选日期：2026-09-05
发布状态：`v0.46.2` tag 与 GitHub Release 已创建并推送至 `origin`；当前公开版本为
[`v0.46.2`](https://github.com/a2787/ub-utils/releases/tag/v0.46.2)。

## 用户可见变化

- B站主评论菜单中的楼操作显示为「🧵 屏蔽回复」，使用四字短文案以适配真站约 120px 宽的菜单；按钮的 `title` 和 `aria-label` 仍保留完整语义「屏蔽该楼回复」。
- B站子评论点击真实三点菜单后，会触发一次有界菜单补扫；只要当前子评论身份可由已有 `bili:uid` 路径确认，就会出现「🚫 本地拉黑」。
- 子评论不会显示只适用于主评论的楼回复入口；主评论的楼操作分页、确认和恢复语义不变。

## 实现与回归

- 真站 `BILI-COMMENT-ACTION-BUTTONS-RENDERER` Shadow DOM 的更多按钮由 `#more` 容器和 `bili-icon[icon="BDC/more_vertical_fill/1"]` 组成，且没有可依赖的 aria/class 文案。候选仅在该评论操作组件及主/子评论祖先链内识别该触发器，点击后复用已有一次性菜单扫描。
- 真站 B站菜单位于 Shadow DOM 内，document 级 `white-space` 规则不会穿透到插入的 `li`；候选对菜单入口设置内联单行约束，并缩短楼操作的视觉文案，避免六字标签在原生菜单宽度内折行。
- 弹幕举报仍只有在存在唯一、未过期的 `mid_hash` 身份时才注入可执行本地入口；评论菜单仍通过当前评论节点解析 `bili:uid`。
