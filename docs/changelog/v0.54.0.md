# OmniBlock v0.54.0 — 独立 AI 评测与受控事实核查

日期：2026-09-10
状态：已发布

## 用户可见变化

- AI 设置增加“事实核查”模式：`off`（默认）、`shadow` 和 `canary`。
- `off` 保持 v0.53.1 的保守事实边界；`shadow` 只在本机累计请求/结果数量，不改变 AI 候选；`canary` 只允许本机 allowlist broker 提供的受限事实证据辅助第二次模型判断，结果仍进入原有人工审核。
- 事实核查不会自动屏蔽、不会直接写本地名单、不会扩大 UID/hash 身份关联，也不会调用平台举报、官方拉黑、关注或发帖接口。
- 没有来源、来源冲突/过期/不可访问、证据不足或 broker 失败时统一保守延期；切换设置、停用 AI 或换路由会清理事实缓存。

## 安全与网络边界

本版本只支持 loopback-only 的本机事实 broker：默认地址为 `http://127.0.0.1:4001/v1/fact-check`，来源必须由用户在本机 broker 配置的显式 allowlist 提供。插件只发送 ordinal claim id 和脱敏后的事实文本，不发送 UID、`mid_hash`、昵称、页面 URL、Cookie、Token、Key 或原始平台对象；响应只保留受限来源元数据，不把原始来源 URL 返回到页面。默认 allowlist 为空，插件不会自行访问公共搜索或开放网页。

事实检索与策略分类分开：事实证据不能替代人工确认，不能改变身份可信度，也不能绕过既有 `hash-only`、卡片校验、撤销和会话隔离规则。

## 回滚与发布

- 运行时可切回 `off`，清除本机事实缓存并回退 `not_checked/defer`；删除或停用本机 broker 不影响普通 AI 候选链和已有本地名单。
- 若出现身份越权、原始文本落日志、公共网络越界、误阻断上升、跨会话写入或资源失控，立即关闭 shadow/canary，回退到 v0.53.1 的事实边界。
