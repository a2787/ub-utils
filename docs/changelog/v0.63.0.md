# OmniBlock v0.63.0 - 自建界面深色模式

日期：2026-10-27。计划项：OB-UI-003（见 [PLAN](../maintenance/PLAN.md)）。状态：本地候选，未发布（v0.59.0 仍为最新公开版本；v0.60.0~v0.63.0 在本地队列）。

## 背景

全部自建 UI 样式此前是硬编码浅色（`#fff/#fafbff/#222/#444` 家族），系统深色偏好下会出现大片
浅色残块。用户 2026-10-27 采纳"跟随系统自动深色，不加独立开关"的方案（OB-UI-003）。

## 用户可见变化

- **自动深色模式**：系统处于深色（`prefers-color-scheme: dark`）时，脚本自建界面自动切换为
  深色主题，浅色主题规则原样保留、不受影响；没有新增开关，也不改动平台页面自身的配色。
- 覆盖面：设置面板全部分区/行/按钮/输入框/名单列表、统一内容弹窗（标签页与嵌入的评论/弹幕
  管理器行）、AI 审核浮层（候选行/复选框/作用域下拉/拒绝按钮/反馈面板）、关键词面板（规则行、
  就地编辑输入、样本区；`.ob-auto-rule-hits`/`.ob-auto-rule-scope` 徽章保留色相但换成深色底）、
  确认气泡与新确认浮层、作品级确认框、批量范围面板、AI 待审浮条与后台状态浮条、撤销 toast
  （本就是深色）、日志 viewer（`pre` 块保持深底等宽字体）。
- 深色下原生表单控件（select/checkbox/日期/滚动条）经 `color-scheme: dark` 随主题变暗；
  该声明只作用于脚本自建浮层根节点，不触碰平台页面。
- 对比度：正文 `#e8eaf2` 于 `#1c2030` 家族底色（对比约 13.6:1，AA 以上）；次级/弱化/禁用文字
  分级可辨；深色下为自建界面补了 `:focus-visible` 键盘焦点描边。
- 主名单存储状态行的颜色由内联样式按状态写入，深色下通过 `data-level`（critical/warning）与
  样式属性选择器替换为深色友好色；常态 `#999` 对比约 5.7:1 保持不变。

## 实现方式与边界

- 浅色规则一行未改：深色是样式表**末尾纯追加**的 `@media (prefers-color-scheme: dark)` 覆盖段
  （142 条选择器规则），设计令牌（`--ob-dark-bg/--ob-dark-text/...`）只在该媒体查询内定义和引用。
- 零 JS 行为改动：本轮只新增样式表内容（含 `color-scheme: dark` 声明），不改任何逻辑、布局、
  尺寸或 z-index；`:hover` 均有深色等价规则。
- 平台页内的行内入口按钮（`.ob-quick`/`.ob-work-block`/`.ob-dm-block`/微博作者入口/折叠恢复条）
  的浅色规则带 `!important`（其中 `.ob-bar` 另有内联样式），深色覆盖段以同权重 `!important` 后置
  覆盖，仅深色媒体查询激活时生效。

## 证据

### `structure regression`

- 新增 `test/dark-mode.cjs` 18 项（夹具为人工合成 B站评论 DOM，沿用 ui-settings 合成结构）：
  - DARK-2（源码级）：样式表末尾存在深色覆盖段、含 ≥40 条规则（实测 142）与 `color-scheme: dark`；
    全样式表只有 1 处 `@media (prefers-color-scheme`（浅色规则无媒体查询改动）；深色设计令牌就位。
  - DARK-1（浏览器级，Playwright `emulateMedia`）：深色下设置面板/内容弹窗/确认气泡/自建确认浮层
    背景亮度 0.015（<0.25）、正文亮度 0.824（>0.7）、输入框 `rgb(38,44,62)/rgb(232,234,242)`、
    `#ob-panel` 计算色 `color-scheme=dark`；同一批元素切回浅色后恢复白底（亮度 1.000）深字
    （亮度 0.016），`color-scheme` 计算值回到 `normal`——证明切换真实由 `prefers-color-scheme`
    驱动，不是写死的深色。
  - DARK-3：浅色（默认）下快捷拉黑 → 确认气泡 → 名单写入 → 撤销 toast 链路与旧行为一致。
- 本轮其余矩阵：`node --check`、`test/run.cjs` 20/20、`test/userscript-product.cjs` 7/7、
  `test/ui-settings.cjs` 16 项全绿；页面/控制台错误 0；docs-check、隐私门禁通过。

### `blocked`

- 真实站点验证未执行（2026-09-12 起实页验证暂停）。深色模式是纯 CSS 媒体查询，无平台结构依赖；
  恢复实页验证后可在系统深色的浏览器中抽查一次真实页面上的面板/弹窗观感即可，无新增 DOM 断言需求。

## 已知限制

- 深色只跟随系统，无独立开关（如需用户手动切换另立计划项）。
- 平台页面本身在深色站点上的配色不受本脚本控制；行内入口按钮在深色站点浅色区块上仍为深色底，
  这是跟随系统而非跟随站点配色的刻意取舍。
- `#ob-storage-status` 持久化错误红色依赖 `style` 属性序列化（`rgb(198, 40, 40)`）匹配，若浏览器
  序列化格式变化则该子状态回退为原始 `#c62828`（对比约 2.9:1），critical/warning 两级仍由
  `data-level` 规则覆盖。
