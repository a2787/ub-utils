# OmniBlock v0.57.1：无 hover 触控入口补齐

日期：2026-09-11
状态：已公开发布（[tag/Release](https://github.com/a2787/ub-utils/releases/tag/v0.57.1)）

## 用户可见变化

- 在平板、手机和其他 coarse pointer/无 hover 设备上，右下角页面级“内容屏蔽/弹幕屏蔽”入口常驻可见；不再要求先把鼠标移到齿轮上才能找到屏蔽弹窗。齿轮继续直接打开设置面板。
- 触控设备上的齿轮、页面入口、设置/内容管理器/AI 审核/确认框按钮和主要输入控件按至少 44px 触控目标处理；长列表保留纵向触摸滚动，并继续考虑安全区和可用视口高度。
- 抖音滚动弹幕支持点按目标后显示自有“🚫 拉黑”入口；B站播放器内 `pointer-events:none` 的浮动弹幕支持点按目标后显示可点按的自有入口。两者都不触发平台举报、拉黑或关注。
- 桌面鼠标仍保留原来的控制坞悬停展开、action hold 和空闲收起行为；本版本没有改变 AI 直连、Key 隔离或账户加密同步协议。

## 实现边界

- `FloatingDock` 根据 `pointer: coarse`、`hover: none`、`navigator.maxTouchPoints` 以及实际 touch/pen pointerdown 进入触控模式。触控模式使用展开状态并停止 hover/focus 离开后的自动收起，动态出现的页面入口也会立即可达。
- 触控模式只改变 OmniBlock 自有 UI 的可见性和触控尺寸，不修改平台页面的交互控件；平台原生菜单仍由用户点按平台自己的“三个点/举报”等入口打开，本地按钮只在可验证身份上下文存在时注入。
- 设置面板内的账户/Key/规则/提示词/反馈按钮组与 AI 审核/反馈浮层的确认、取消、拒绝、作用域按钮带组件级紧凑 `min-height`（26–34px），窄屏断言（≤560px）内会被重新抬高，但平板等 561px 以上触控宽度不会被覆盖；coarse-pointer 块已在组件规则之后统一恢复 44px 触控目标，关闭按钮同步放大为 44×44。
- B站浮动弹幕继续使用当前弹幕矩形和唯一 `mid_hash` 候选进行坐标命中；触控点按只复用该只读命中链路，并让自有按钮短时间保留，未确认的歧义文案仍不提供入口。
- 抖音弹幕点按复用既有 `extractDanmaku` 身份解析；没有可靠身份、已在名单或关闭入口时仍不显示可执行按钮。

## 验证证据

- `structure regression`：`node test/run.cjs` 20/20；新增 E4 触控控制坞分支，确认不派发 hover 也能让页面入口可见、打开内容弹窗并打开设置。
- `structure regression`：`node test/userscript-product.cjs` 6/6；390px 与 768px 触控视口确认入口可达、按钮尺寸、设置/内容弹窗和无横向溢出，并新增 768px 审核浮层触控目标断言（mock provider 回显候选驱动真实审核浮层，旧行为 26/32px 上失败）。
- `structure regression`：`node test/quickblock.cjs` 38/38；B站浮动弹幕同时覆盖鼠标悬停和 touch pointerdown 坐标命中。
- `structure regression`：`node test/adapters.cjs` 28/28；抖音弹幕同时覆盖鼠标悬停和 touch pointerdown，自有按钮仍按 UID 屏蔽、隐藏、撤销。
- `real-site verified`：2026-09-11，匿名隔离只读会话，脱敏页面形式 `bilibili.com/video/...`；v0.57.1 候选（含触控目标修复，SHA-256 `2efe63df…`）实际加载，观察到 2 个评论 renderer、1 条作品内容、2 条评论、77 条弹幕（AI 记录 80 条），内容弹窗 4 个标签，本地拉黑/撤销恢复通过，页面和控制台错误为 0。该探针验证真实页面加载和入口结构，不把桌面鼠标结果扩大为平板触控结论。
- `blocked`：目标平板的真实 Edge + Tampermonkey 触控操作尚未在本版本候选上重新观察；抖音匿名探针停在验证码中间页，未取得真实弹幕触控样本。

## 安装与回滚

- v0.57.1 已经用户当轮授权发布：功能提交推送到 `origin/master`，`v0.57.1` tag 与 GitHub Release 已创建；`@updateURL`/`@downloadURL` 指向 raw master，现已服务 `0.57.1`，Tampermonkey 下次检查更新时自动升级，也可在管理面板手动“检查更新”。
- 回滚时保留用户现有 Tampermonkey 数据，只恢复已知可用的 v0.57.0；本版本没有修改同步服务、数据库 schema 或账户数据。
- 目标平板实机触控验证仍为 `blocked`；发布说明未把触控实机写成已验证，设备结果回填后再补记 `real-site verified`。
