# OmniBlock v0.64.0

日期：2026-11-23 · `@version 0.64.0` · 构建：`0.64.0-personal-oneclick`

状态：本地候选已完成结构回归与 B站/微博真站复核；tag/Release/raw 在发布轮回写（见 `docs/maintenance/CURRENT.md`）。

本版把“看到内容 → 本地屏蔽”压缩为一次点击，并把失败可见性、设置入口和维护链一起收口。控制坞外观、低调脚本名、`@namespace`、`@updateURL`、`@downloadURL` 均未改变。

## 用户可见变化

### 一键屏蔽

- 作者入口（微博帖子、B站视频/动态）与快捷入口（评论/原生菜单）默认直接写入本地名单并立即隐藏，不再弹二次确认。
- 批量、弹幕和 UID 候选始终保留确认气泡；`bili:dmhash` 即使从共享 `.ob-quick` 工厂进入，也按 `danmaku` 处理，不能绕过确认。
- 想恢复二次确认：设置 → 关闭「快捷/作者入口直接屏蔽」。批量/弹幕/UID 的确认不受该开关影响。
- 首次直提 toast 最多追加 3 次「可在设置关闭直接屏蔽」；打开设置后永久停止，不新增常驻 UI。

### 撤销安全网

- 撤销 toast 默认 10 秒，可在设置按 5–30 秒调整。
- 新增菜单命令与设置按钮「撤销上一次本地屏蔽」；最近操作仍保留 20 条可逐条撤销。
- 撤销与批量/弹幕写名单共用同一批 keys，不产生“撤销后仍显示可撤销”的假状态。

### 失败可见与诊断

- 设置 → 日志诊断新增 Health 卡：存储、日志字符数、备份状态与最近错误；不显示正文、URL 或 Cookie。
- 主名单写入失败时 `Health.ok` 变为异常，并在下一次主动屏蔽 toast 追加一次「本地存储异常，详见设置→日志诊断」；不改变控制坞外观。
- 事件日志默认保留 7 天 / 单日 5 千条 / 总 2 MiB；旧分片自动收敛。
- 备份读取失败（坏 JSON、读取异常）标记 `corrupted`，后续快照写入跳过，不覆盖唯一恢复来源。
- 关键静默失败（最近操作、规则命中/样本、AI 已分析缓存/用量、备份 sink）改为内部错误记录；用户主动动作失败仍有可见 toast。

### 设置与更新

- 设置「屏蔽与名单」顶部新增「打开当前页内容屏蔽工作台」；「规则」分组新增「打开 AI 设置」；最近操作标题旁新增「撤销上一次」。
- 移除「屏蔽与名单」中与规则分组重复的 `#ob-open-rules-*` 按钮，避免同一功能两套入口。
- 首次提示改为「作者旁或‘⋯’菜单里点‘本地拉黑’；撤销默认 10 秒」；旧 `ui-hint:v1` 用户不会再次看到提示，README/changelog 承载精确路径。
- 更新检查增加 15 秒超时和 `ontimeout`；无设置面板（GM 菜单/检查中关闭面板）时所有终态改用 toast，不再“点了没反应”。

### 维护与发布链

- README 拆为一页快速开始 + `docs/usage/PLATFORMS.md` + `docs/usage/AI-AND-SYNC.md`；README 约 9 KiB。
- CI push 保留既有 22 项，补入 `ui-settings`、`dark-mode`、`rule-manager`、`rule-samples`、7 个本地 headless AI 套件与 `code-health`；`degraded-storage` 仍需 Edge/Chromium 非 headless 专用环境，`gateway-smoke` 需 Docker，记 `blocked`。
- 新增 `test/code-health.cjs`：空 catch 114 / 总行数 23500 / CSS 120000 字符上限，只允许基线下降或持平。
- 新增 `scripts/release.cjs`：默认 dry-run；`--publish` 需 `--confirm-manual-gates`；校验目标树内 version/build、工作区干净、gh auth、既有 tag 同/异 commit、tag 路径 raw 6×15s；脚本不 commit。

## 边界与限制

- AI、账户同步和平台数据源行为本版未改；AI 仍默认关闭、只提议、必须人工确认，不调用平台举报/官方拉黑/关注/发帖。
- 身份无法可靠解析时仍不生成可执行入口；`bili:dmhash` 永远不伪装成已知 UID。
- 列表/关注流作者卡不在本版默认入口声明内；需要真实结构确认后再扩展，不以详情页可用代替。
- 控制坞收起态、透明度与齿轮位置保持不变；不加入新手引导、平台总开关或全局快捷键。
- 本条目为本地候选证据；发布后的 tag、Release 与 raw 在 `CURRENT.md` 回写。
