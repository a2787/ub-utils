# OmniBlock v0.45.0

发布日期：2026-08-29
Release：[GitHub Release](https://github.com/a2787/ub-utils/releases/tag/v0.45.0)

## 用户可见变化

- 通用扫描器使用共享 MutationObserver、增量脏节点和 Shadow DOM 单次遍历；后台标签页暂停非必要观察，恢复时再同步。
- B站/抖音弹幕、作者入口、作品入口、快速菜单和批量入口按活动信号置脏、低频合并刷新；抖音播放器根节点和视频会话键复用，
  避免逐条弹幕重复递归遍历整页。
- 评论管理器、微博评论缓存和弹幕观察索引设置明确上限；缓存不持有虚拟列表 DOM 引用，达到上限时显示“部分”边界。
- 日志继续逐条记录用户操作、屏蔽/恢复、状态转移和错误；DOM/扫描等被动事件改为 10 秒窗口聚合，降低空闲写入和内存压力。
- 右下角入口统一进入浮动控制坞：齿轮默认半隐藏，悬停或键盘聚焦时展开；评论/弹幕入口随控制坞联动，移入入口时保留交互窗口，
  打开面板后继续展开，关闭或空闲后收起；遵循系统“减少动态效果”偏好。
- 增加本地 MV3 持久开发扩展、GM 存储桥接和无源码注入双新页探针；专用浏览器开发迭代不再依赖对单个页面临时注入。

## 结构与维护变化

- 保留单文件 userscript 的闭包模块边界，在没有打包/加载顺序证据前不进行形式拆分；用生命周期、运行锁、缓存上限和回归矩阵
  收敛真实运行风险。
- 已安装运行时探针改用直接页面级 CDP，兼容 Chrome 148 在本机专用 profile 上浏览器级 `connectOverCDP` handshake 超时的情况。
