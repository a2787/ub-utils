# OmniBlock v0.56.0：作品语境 AI 请求压缩与 OB-AI-014 收口

日期：2026-09-10
状态：已发布

## 用户可见变化

- 作品语境的判断边界不变：标题/简介、真实回复关系和已观察弹幕位置只帮助解释正文；AI 仍必须命中当前规则并经过人工确认，语境不足不会自动扩大屏蔽。
- loopback AI 请求升级为 `contextSchemaVersion=2` 的紧凑形态。同一作品批次把 `work/part/sufficiency` 提升为 `contextCatalog.defaults`；无额外差异的条目省略 `context`，弹幕时间使用 `[progressMs, segmentIndex]`，父评论使用 `[relation, text]`。
- 同一批次如果包含多个作品、多个分 P 或无法安全归并的上下文，自动保留显式上下文形态，不为了节省字符合并不同语境。浏览器内的完整 `WorkContext/LocalContext` 不变，压缩只发生在发往本机网关的 prompt 线协议。
- 持久开发扩展的主世界、隔离世界和 service worker 白名单同步支持 v2；仍拒绝 URL、UID、弹幕 hash、Cookie、Token 和原始平台对象。

## 为什么要做

v0.55.0 的真实 B 站探针发现，同一作品的 80 条弹幕批次中，显式 `workId/itemId/sufficiency/time` 会使输入字符增加约 87%～115%。这会放大等待时间和本机模型成本，不能作为长期形态保留。本版本只压缩重复协议字段，不改变作品作用域、规则命中、事实核查或身份门禁。

## 收口决策与边界

- 已完成并关闭：作品上下文采集、当前作品作用域、人工审核即时确认、脱敏 ordinal 出站、v2 紧凑 payload、桥接白名单和单作品预算验证。
- 封存为远期预留：真实用户标注集驱动的长期语境精度。这需要经过同意和脱敏的标注数据，当前没有数据基础，不把合成评测结果写成真实准确率。
- 封存为远期预留：字幕/音频/画面语义。当前真实页面没有标准可读字幕轨道，播放器只提供媒体存在证据且没有音频轨道元数据；画面语义探针不读取视频帧。只有出现稳定、可授权、可读的来源并另立隐私/成本/多模态计划后才重新评估。
- 持续边界：登录状态、根评论分页和懒加载只影响探针覆盖，不被推断为全量内容；未执行平台写入，不读取或导出凭证。
