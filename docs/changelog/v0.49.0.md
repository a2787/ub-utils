## 用户可见变化

- B站和抖音视频页的评论/弹幕入口合并为一个「内容屏蔽（评论/弹幕）」按钮；按钮打开同一个三标签弹窗，标签分别为「屏蔽评论」「屏蔽弹幕」「AI 屏蔽」。切换标签会关闭上一标签的子管理器和进行中的弹幕时间轴扫描。
- AI 配置从设置页迁移到 B站/抖音内容弹窗的「AI 屏蔽」标签；该标签保留启用开关、loopback 网关/模型设置、预设规则、本页面附加规则、取消、进度和人工审核。设置页不再渲染 AI 配置控件，只显示迁移提示。

- 抖音设置页的「分析本页」在详情页显示为「加载并分析本页」。一次点击会依次展开明确的回复入口、在评论容器内有限滚动、扫描当前视频弹幕时间轴，再把本次实际观察到的全部内容送入 AI 分批分析；用户不再需要先打开评论管理器、再切回设置页。
- 加载期间显示评论观察数和弹幕时间轴进度，并提供「取消当前分析」。取消、换片、网关失败或桥接失败会结束当前任务，不把旧视频记录带入新任务。
- 加载仍只复用页面可见的评论/弹幕路径，不调用抖音私有接口，不执行举报、拉黑、关注、发帖等平台写入；平台显示总数不会被当作已经加载的记录数。
- AI 结果仍进入原有人工审核框；确认前不写入本地名单，无可靠身份的候选不可执行。B站和其他平台保留原来的“只分析已观察内容”入口。

## 实现与安全边界

- 评论加载器和弹幕时间轴扫描器均接受 AbortSignal；同一 run 串行加载评论和弹幕，使用活动视频会话边界，完成后再收集记录并进入既有分批协议。
- 播放器的播放/暂停/控件显隐 class 变化不再被误判为换片；只有明确的 `video_<id>` 或身份 data 属性变化才会取消旧会话。取消会释放加载器、请求和弹幕时间轴扫描。
- 未改变网关 loopback 校验、请求脱敏、人工审核、规范身份和名单写入门槛；未修改 provider 配置、系统服务、注册表或 V2。

### `blocked`

- 匿名抖音入口仍可能进入验证码中间页；这不影响本轮用户授权登录态证据，但不扩写为匿名全站通过。
- 本轮匿名抖音入口实际落在验证码中间页，无法对统一三标签宿主做真站 UI 验收；需要新的登录态只读授权后补测。
- 商汤“日日新”、额度耗尽、长期 cooldown/fallback 仍不属于本版本；官方 DeepSeek 的历史 provider 联调沿用 OB-AI-001 记录。
