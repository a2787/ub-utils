# OmniBlock v0.55.0：作品语境感知的 AI 屏蔽

日期：2026-09-10
状态：已发布

## 用户可见变化

- B 站视频详情页的 AI 分析现在会把当前作品的标题、简介、分 P 信息，以及已明确建立的回复父评论和弹幕时间位置作为对应条目的语境资料；不同作品、不同楼层和不同弹幕位置不会只凭相同文字自动合并。
- AI 审核行增加作用域选择。默认是“当前作品”，确认后先在当前作品会话内隐藏已观察到的内容；只有用户明确改成“全局作者”，且条目有可靠身份，才写入原有全局名单。当前作品作用域可以通过本次撤销入口撤销，换路由时自动清理。
- 作品语境只改变对正文的解释，不能单独成为屏蔽规则。模型没有返回足够语境、返回未知规则 ID 或缺少新协议字段时，客户端延期，不生成可执行候选。
- B 站 AI 弹幕记录保留消息实例、分段和进度，不再把同一发送者的多条弹幕压成一条代表文本；当前作品作用域只精确命中对应消息实例。

## 安全与边界

- 发往本机 loopback 网关的语境使用 `w1/p1/i1/r1` 一类 ordinal ID；作品标题/简介在同一批次的 `contextCatalog` 中只发送一次，条目只携带必要引用、父评论和时间字段。开发扩展主世界、隔离世界和 service worker 三层都对白名单字段再次校验。
- 旧网关/旧模型缺少 `contextSufficiency` 时按语境不足延期；旧的无语境负反馈不会跨作品命中，语境反馈按作品、内容实例、父评论和弹幕位置隔离。
- 本版本仍不理解视频画面、声音或字幕；没有经过独立捕获和评测的字幕/音频来源不会自动接入。事实核查仍遵守 v0.54.0 的 `off/shadow/canary` 和人工审核边界。
- 不调用 B 站举报、官方拉黑、关注、发帖等写入接口，不读取或导出 Cookie、Token 或凭证；当前作品作用域只保存在浏览器会话内，不改变既有存储 schema。
