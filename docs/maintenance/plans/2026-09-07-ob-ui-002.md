# OB-UI-002：B站/抖音统一内容屏蔽标签弹窗

- 日期：2026-09-07
- 状态：verified
- 范围：B站和抖音视频页各使用一个「内容屏蔽（评论/弹幕）」入口；宿主弹窗提供「屏蔽评论」「屏蔽弹幕」「AI 屏蔽」三个标签。AI 网关、模型、规则、分析进度、取消和人工审核从设置页迁移到第三个标签。
- 非目标：不改变微博/知乎/贴吧/X 入口、平台选择器、身份键、AI 脱敏/loopback 边界、名单语义或平台写入边界；不执行 push、tag、Release、部署或平台写入。
- 依赖：OB-AI-001、OB-AI-002。

## 实现

- 新增统一内容宿主和标签切换生命周期；切换时关闭评论/弹幕子管理器，释放键盘监听、FloatingDock 和弹幕时间轴扫描。
- B站视频页在弹幕能力初始化后刷新为统一入口；普通 B站非视频页保留原评论批量入口，避免扩大入口范围。
- AI 控件抽成可挂载到宿主标签的 surface；设置页仅保留迁移提示。抖音 AI 标签继续支持一键加载评论/弹幕、全量分批和审核。
- 修复 B站旧弹幕工具移除后 `refreshDmTool` 提前返回导致嵌入面板不重绘的回归。
- 更新人工合成回归和 B站/抖音真实探针，使其通过统一入口切换标签，不再依赖旧的独立按钮。

## 证据

- `structure regression`：`node test/run.cjs` 20/20；AI screening/bridge/batch/autoload、comment-manager 3/3、quickblock 36/36、danmaku-auto 7/7、adapters 28/28、douyin 2/2、docs-check 和 `node test/dev-browser.cjs build` 均通过；构建 `0.49.0-content-manager-tabs`。
- `real-site verified`：2026-09-07 匿名隔离 B站视频页（页面形式 `bilibili.com/video/...`，未登录）实际显示统一入口和 3 标签；评论管理器 2 行可读取/搜索/全选，弹幕管理器 16 组/15 位发送者可单条与批量屏蔽后撤销，浮动弹幕本地入口可屏蔽/撤销。未读取 Cookie，未点击 B站举报、官方拉黑、关注或发帖控件；根评论分页为 partial。
- `blocked`：2026-09-07 抖音匿名隔离入口为「验证码中间页」，没有可验证的视频评论/弹幕条目；抖音真站三标签登录态结果等待用户当轮授权。
