- status: verified
- completed: 2026-09-07
- scope: B站统一内容入口右下定位、评论/弹幕正文清理，以及已选弹幕目标的 hash→UID 按需关联。
- non-goals: 不修改其他平台适配器、B站平台写入、Cookie、数据库、部署、发布或页面初始全量 UID 反查。

- implementation: `omniblock.user.js`；受影响回归为 `test/quickblock.cjs`、`test/ai-screening.cjs`、`test/real-bilibili-probe.cjs`；持久化开发扩展的 B站卡片 GET 白名单桥接位于 `test/build-dev-extension.cjs`，并由 `test/dev-extension.cjs` 锁定。
- `structure regression`: quickblock 37/37、AI 13/13、评论管理器 3/3、自动弹幕 7/7、适配器 28/28、运行器 20/20、持久化开发扩展 6/6；语法、文档和差异门禁通过。
- `real-site verified`: 2026-09-07，公开 B站视频页（页面形式 `bilibili.com/video/...`，登录状态未判定）捕获真实 `bili-rich-text`、操作组件和菜单；匿名隔离探针观察到评论/弹幕/浮动入口链路；独立持久化 Edge 临时 profile 未注入页面源码，自动加载当前 MV3 构建，观察到 48 行弹幕，按需查询 2 个单 hash 目标后得到 1 个唯一候选，点击后无二次确认且 UID/hash 同时进入本地索引，撤销后均恢复，页面错误 0。
