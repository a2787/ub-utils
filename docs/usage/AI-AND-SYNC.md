## AI：只使用设备直连 API

- provider 配置只保留三项：OpenAI-compatible API 地址、模型名和「设置/更换本机 Key」。没有 AI 网关模式，
  也不加入本地模型；事实核查是默认关闭的独立本机 broker，不是 provider 主链路。
- API 地址默认要求 HTTPS；本机测试可使用 `localhost`、`127.0.0.1` 或 `::1` 的 HTTP 地址，不能带账号、
  密码、查询参数或片段。请求通过 Tampermonkey 的 `GM_xmlhttpRequest` 发出，Key 只在当前设备的独立 GM
  存储中读取到内存后放入 `Authorization` 请求头，不进入请求正文、页面对象、名单导出、提示词导出、日志或
  同步文档。
- 脚本头中的 `@connect *` 允许用户自行选择 provider；Tampermonkey 第一次访问新的 API 域名时可能弹出跨源
  权限提示，只应批准自己信任的地址。缺少 Key、地址无效、网络失败、超时或 HTTP/JSON 格式错误都会保留为
  可诊断的失败状态。
- AI 关闭时不发送页面内容。AI 结果仍必须经过人工审核：候选只有在审核界面明确确认后才写入本地名单，
  不会直接调用平台举报、官方拉黑、关注或发帖。

## 触发方式与自动模式的省钱边界

- 启用 AI 后默认仅手动分析：只有点击「分析本页」才会把当前页已经观察到、截断后的作者作品内容、评论、
  弹幕或帖子正文发送给用户直接填写的 API；页面加载和滚动不会自动请求（抖音按钮会先自动加载评论/弹幕
  再分析本页）。
- 需要自动模式时单独勾选「自动分析新内容」：页面加载和内容更新时自动分析，候选不自动弹窗，而是等在
  屏幕右侧的「AI 待审建议」浮条里，点击后进入同一套多选人工审核；路由切换或关闭 AI 时清空浮条。
- 自动模式有三项省钱边界：① 自动分析成功过的记录进入本机已分析缓存（独立本地存储键，只存记录 ID 与
  时间戳，TTL 7 天、上限 2000 条，不含正文/昵称/身份键，不入同步或导出），重访同一页面不再重复产生
  请求；规则、提示词配置、API 地址或模型变化时缓存整体失效并重新分析。② 自动模式每页最多发送 3 批
  （每批 80 条），超出后状态栏提示「已达本页自动分析批量上限……可用「分析本页」手动处理」。③ 可选
  勾选「自动分析只看评论（弹幕仅手动分析）」，开启后自动分析跳过全部弹幕。
- 「分析本页」手动分析不查询也不写入该缓存、不受批量上限约束，始终完整重新分析。AI 面板底部显示本机
  用量计数（本次页面与当日累计的请求数/条数/字符数，仅本机保存，不含正文与身份）；状态栏会提示「本地
  名单/关键词已先行处理 N 条，未发送 AI」——关键词/正则规则与本地名单命中的内容不进入 AI 请求。

## 各平台 AI 采集范围与审核语义

- **作者作品内容**：AI 记录读取当前展示形态的语义正文，标注 `contentType`；B站视频/推荐/动态、抖音播放器、
  微博帖子、知乎回答/文章/想法/专栏/问题/视频、贴吧旧版/新版主题帖和 X 帖子均有结构回归。不会把作者名、
  时间、点赞、回复、举报、分享、展开等操作文案送入 AI；登录、验证码或结构阻断仍按 `blocked` 记录。
- B站和抖音启用 AI 后，会把当前页面已观察到的作品正文、评论和弹幕送入同一套审核提醒；抖音精选/搜索结果
  和主页「作品」也进入作品正文读取。微博和知乎把当前页面已观察的帖子/回答/文章/想法及评论一并处理；这些
  内容的作者身份若暂缺仍可作为只读 AI 样本，候选在现有人工审核弹窗中确认后才会写入名单。评论晚于首轮
  加载时只增量分析新记录，不会把操作按钮文字当作正文。
- B站视频详情页的 AI 审核会显示当前作品作用域：标题/简介只通过共享作品目录进入对应批次，回复只关联真实
  父评论，弹幕只使用已观察的分 P/进度；同一句文字跨作品或跨楼层不会直接复用屏蔽结论。确认行默认「当前
  作品」，需要跨作品屏蔽作者时必须手动切换为「全局作者」且有可靠身份。没有足够语境时会在审核说明中计为
  延期；本功能不读取字幕、音频或视频画面来猜测含义。
- 执行弹幕屏蔽/确认 AI 弹幕候选时的 hash→UID 关联与后台补充行为见
  [平台适配细节 · B站](PLATFORMS.md)。

## 关键词/正则自动规则（B站与抖音）

规则在各自「内容屏蔽」弹窗**「关键词屏蔽」**标签管理：支持添加、启停、就地编辑（类型/内容/备注/作用域
一次改完，保存后即时生效，不再删除重建）、每条规则的本机命中计数（可清零，跨会话保留）以及规则包
导出/导入；规则还可选「两个平台通用」同时作用于 B站和抖音，旧规则仍只在原平台生效。设置面板的「平台专用
屏蔽入口」提供「B站规则管理」「抖音规则管理」按钮，任意页面都能打开同一个管理界面。规则只在本机匹配当前
已观察到的评论或弹幕正文，命中可靠身份后自动走该平台已有的本地屏蔽链，不触发举报、官方拉黑或 PAKKU 去重，
也不请求 AI。B站普通弹幕没有原始 UID 时保留 `mid_hash`，唯一且经公开用户卡片正向校验的候选才与 UID 关联；
抖音没有可靠身份的命中只隐藏当前节点，不写入猜测身份。规则命中的发送者可在弹幕管理器点「恢复并例外」：
当前身份恢复显示并加入对应平台例外列表（其他命中仍屏蔽）；关键词屏蔽标签里的「恢复规则」删除例外并让
规则重新作用于该身份。删除规则只停止后续自动匹配，已写入本地名单的普通身份仍需在名单中手动删除。

## 已屏蔽内容样本与 AI 归纳规则

- B站和抖音的关键词屏蔽标签里有**「已屏蔽内容样本」**区：每次在确认气泡、批量确认、作品确认、弹幕确认或
  AI 审核确认中拉黑时，该条内容正文（截断 240 字）进入本机样本库（按平台分桶、每平台最多 200 条，仅存
  本机，不进入账户同步、名单导出、备份或日志；关键词自动规则写入与后台 UID 增强不产生样本）。样本区显示
  最近 50 条（正文 + 相对时间），可逐条「转为关键词」、勾选后「把选中转为关键词」批量转换（走规则的完整
  校验，重复、超限或无效会被跳过并提示），也可「刷新」「清空样本」；转换不会删除样本。
- AI 配置齐备时可点**「AI 归纳提炼规则」**：把该平台最近 100 条样本正文发给已配置的 AI，归纳出候选关键词/
  正则（请求只含样本文本，不含身份键或 URL）；候选只进入确认列表——关键词默认勾选、正则默认不勾选，点
  「把选中加入规则」后才写入规则表，重复/超限/危险正则会被拒绝并显示原因；未配置 provider/模型/Key 时
  按钮禁用并说明原因，请求失败给出可读错误且不写入任何规则。AI 归纳是独立的一次性请求，不影响自动分析，
  也不把结果冒充自动决策。

## 账户级客户端加密同步

- 设置面板提供「注册账户」「登录」和「立即同步（合并）」。每台设备登录同一账户，并在点击同步时输入同一个
  独立的同步口令；脚本不会保存账户密码或同步口令，也不会自动上传。
- 客户端把名单/规范身份、可同步设置、AI 提示词个性化和反馈账本拆成带设备逻辑时钟的记录，删除使用墓碑，
  再用 PBKDF2-SHA-256 派生 AES-256-GCM 密钥加密；服务端只保存 opaque 密文和 revision，409 并发冲突由
  客户端读取、解密、合并后有界重试。
- API Key、账户登录令牌、账户密码、同步口令、运行日志、自动快照、本地备份和浏览器登录态刻意不进入同步包。
  Key 需要在每台设备单独设置；退出账户只清除当前设备的登录令牌，不删除云端或本地名单。
- 当前仓库的 `sync-server/` 是独立 Python 标准库服务，`sync/` 提供协议和 mock 回归；东京服务器已部署独立
  服务和独立 SQLite 数据库，并通过 HTTPS Quick Tunnel 提供同步入口。Quick Tunnel 重启后可能更换地址，
  当前地址适合电脑/平板互测，不应当作永久域名；长期使用需换成用户自己的 HTTPS 域名或已认证的 Cloudflare
  Named Tunnel，并补做备份、限流、账户删除和密文读回门禁。

## 本地数据、快照与诊断

- 名单与浏览数据默认保存在各自设备的 Tampermonkey GM 存储中；脚本在独立的本地存储键里自动保留最近
  5 份名单快照（可关闭、可恢复上一份）。设置面板可手动按平台 + 身份值添加、删除、导出/导入 JSON 备份；
  快照只用于误删、错误导入或主名单键损坏后的回退，浏览器配置整体丢失时仍应把 JSON 导出到下载目录或
  其他设备。面板显示主名单人数、身份数和序列化体积，接近本地存储边界时给出软提示，不会自动删名单。
- 快捷/批量/作品/弹幕/AI 确认的每次本地拉黑都会记入设置面板「屏蔽与名单」里的**「最近本地屏蔽操作」**
  （最多 20 条，只存时间、类型、数量和身份键，不存正文），每条可点「撤销」，撤销路径与拉黑后的撤销 toast
  一致。撤销 toast 停留时长默认 10 秒，可在同一分组用「撤销确认停留」调整为 5–30 秒。
- 存储桥接未就绪时整页只读降级（开发扩展专用路径；Tampermonkey 正常安装不受影响）：扩展存储桥接故障时
  页面拿不到真实名单，此时改设置或拉黑只在当前页内存生效、绝不写回存储，本地快照也不会新增，避免用空
  名单覆盖真实数据。面板顶部和右下角持续警示「存储桥接未就绪，本页为只读降级模式：名单与设置变更不会
  保存」（浮条可关闭，面板警示保留）；存储恢复后刷新页面即可读回真实名单。桥接的存储快照按分块投递，
  本机日志较多不再导致桥接长期无法就绪；超过保留期（30 天）的历史日志分片（含索引外的孤儿分片）会被
  自动清理。
- 退出本机账户、清空日志、恢复上一份快照和导入失败提示都使用脚本自建的确认浮层，不再弹出浏览器原生
  对话框（AI API Key 输入保留原生输入框，避免输入内容经过页面 DOM）。
- 「日志诊断」分组显示「反馈与日志」区域，可导出完整保留范围内的事件 JSON。设置面板名单按平台分列、
  每列独立滚动，名单上方有搜索框（按备注/身份键不区分大小写过滤）、平台筛选下拉和「显示 X / 共 Y」计数行，
  无匹配时给出空态提示；自动记录了评论或弹幕依据的条目显示备注，悬停名单行可看到「屏蔽依据」。
