## 全局影子穿透兜底 + 一键检查更新按钮（feat，本次收尾）
- **背景**：用户要"不再手动拖文件" + "全局影子 DOM 穿透兜底"。关键现实：用户脚本运行时无法自替换，Tampermonkey 才是唯一种装/更新实体；"一键更新"最彻底是 按钮→拉仓库比版本→有新版自动开安装链接→TM 弹更新页点一次。真正零拖拽靠 TM「更新模式=自动」（一次性设置，永久免拖）。
- **实现（`omniblock.user.js`）**：① 新增 `querySelectorAllDeep(root, sel)` 递归钻所有 open ShadowRoot；② 默认扫描器 `scanOnce` 由 `document.querySelectorAll` 改为 `querySelectorAllDeep(document, sel)`，6 家平台统一穿透（不再只有 B站 单独逻辑）；③ 设置面板「更新」区块 + `#ob-update` 按钮 + 状态行，`checkUpdate()` 用 `GM_xmlhttpRequest` 拉 `@updateURL` 比 `GM_info.script.version`，有新版 `GM_openInTab` 跳 TM 更新页；④ TM 菜单加「检查更新」；`@version` 0.7.0→0.8.0。
- **README**：补「更新方法」三路（一键检查 / 全自动 TM 自动更新 / 手动覆盖）+ 用户脚本无法自替换的现实说明。
- **自测夹具 `test/run.cjs` 扩到 9 项全绿**：A 加载隐藏 / B 未拉黑可见 / C 右键穿透影子 / D 拉黑全流程 / E 面板含按钮 / **F 嵌套影子穿透兜底（Frank=666 双层 shadow 仍隐藏）** / **G 有新版(提示+开安装页) / H 无新版(已是最新) / I 网络错误(检查失败) 三分支**。零控制台报错、零 pageerror。
