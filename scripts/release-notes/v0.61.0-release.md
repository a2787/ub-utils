# OmniBlock v0.61.0 — AI 自动分析的持久缓存、批量上限与只看评论

## 用户可见变化

- **重访同页不再重复计费**：自动模式新增跨会话已分析缓存（稳定记录 id + 时间戳，LRU 2000 条、7 天 TTL；规则/提示词/provider/模型任一变化自动失效）。手动「分析本页」从不读写缓存，行为不变。
- **每页批量上限**：自动模式每页最多 3 批（每批最多 80 条），超出部分状态栏提示可用「分析本页」手动补齐。
- **自动只看评论**：新开关「自动分析只看评论（弹幕仅手动分析）」，默认关闭。
