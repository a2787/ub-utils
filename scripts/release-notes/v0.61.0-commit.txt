feat(ai): persistent analyzed cache, auto batch cap, comments-only option (v0.61.0)

Auto-mode AI analysis gains a cross-session analyzed cache
(omniblock:ai-analyzed:v1: stable record ids + timestamps, LRU 2000, 7-day
TTL, generation invalidated when rules/prompt profile/provider/model
change) so revisiting the same page no longer re-bills the same content.
Auto runs cap at 3 batches per page with a status hint that the remaining
records can be analyzed manually; a new aiAutoCommentsOnly toggle restricts
auto analysis to comments (danmaku stays manual). Manual analysis never
reads or writes the cache and has no cap.

No changes to the request protocol, batch constants, sanitization,
review/confirm flows or the aiEnabled/aiAutoAnalyze gate.
