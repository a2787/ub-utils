# OmniBlock v0.60.0 — 设置面板信息架构与操作一致性

## 用户可见变化

- 设置面板重组为五个可导航分组（屏蔽与名单 / 规则 / 备份与同步 / 更新与关于 / 日志诊断置于最后），顶部锚点导航。
- 名单支持实时搜索、平台筛选与「显示 X / 共 Y」计数；空结果有可读空态。
- 撤销窗口可配置（`undoToastSeconds`，默认 10 秒，5–30 之间）。
- 新增「最近本地屏蔽操作」列表（独立本机存储，环 20 条，不进同步/导出）：逐条撤销人工确认的屏蔽。
- 退出账户、清空日志、恢复快照、导入失败等关键路径改用自建确认浮层；AI Key 输入保留原生（密钥输入路径）。
