# OmniBlock v0.62.0 — 已屏蔽内容样本库与规则提炼

## 用户可见变化

- **样本库**：每次人工确认的本地拉黑会把内容文本（规范化、截短）存入本机样本库（每平台 LRU 200，仅本机，不进同步/导出/日志）。关键词自动规则写入与后台 UID 增强不产生样本。
- **一键转关键词**：关键词面板新增「已屏蔽内容样本」折叠区——勾选样本 → 「把选中转为关键词」，走既有规则校验（去重/上限/危险正则拒绝）。
- **AI 归纳提炼**：门控按钮（需已配置 provider）把最多 100 条样本发给你自己的 AI，按严格 JSON 契约返回候选关键词/正则；候选进入人工确认列表（关键词默认勾选、正则默认不勾选），点「把选中加入规则」才写入，绝不自动添加。
- 失败可解释（provider/网络/解析错误 toast），零部分写入。
