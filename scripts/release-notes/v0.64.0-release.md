# OmniBlock v0.64.0 — Personal 2.0 一键屏蔽与诊断收口

本版把“看到内容 → 本地屏蔽”压缩为一次点击，并补齐撤销、失败可见性、设置入口和维护链。控制坞外观、脚本名、`@namespace`、`@updateURL`、`@downloadURL` 均未改变。

## 用户可见变化

- **一键本地屏蔽**：作者入口与评论/原生菜单里的快捷入口默认直接写入本地名单并立即隐藏，不再弹二次确认；批量、弹幕和 UID 候选仍保留确认。`bili:dmhash` 即使从共享快捷入口进入也按弹幕处理，不能绕过确认。
- **可恢复的直提**：撤销 toast 默认 10 秒（设置可调 5–30 秒）；设置新增“撤销上一次本地屏蔽”和最近操作列表。想恢复二次确认时，关闭“快捷/作者入口直接屏蔽”即可。
- **失败可见**：设置 → 日志诊断新增 Health 卡，聚合存储、备份、日志字符数与最近错误；主名单写入失败会在下一次主动屏蔽时提示。事件日志收敛为 7 天 / 单日 5 千条 / 总 2 MiB；坏备份不会被后续快照覆盖。
- **设置与更新**：设置新增当前页内容屏蔽工作台、AI 设置和撤销入口；移除重复规则按钮；更新检查在设置面板、GM 菜单和面板关闭时都有明确终态。
- **文档与维护**：README 收敛为快速开始，平台细节和 AI/同步边界拆到 `docs/usage/`；CI 补入核心 UI、规则、AI headless 与 code-health；新增通用发布脚本和回归矩阵。

## 更新方式

在 Tampermonkey 中打开本脚本的“检查更新”并点一次“更新”，或在管理面板重新导入版本号更高的 `omniblock.user.js`。更新不会丢失本地名单、设置或备份。

完整变更、证据和边界见 [v0.64.0 完整条目](https://github.com/a2787/ub-utils/blob/master/docs/changelog/v0.64.0.md) 与 [当前维护状态](https://github.com/a2787/ub-utils/blob/master/docs/maintenance/CURRENT.md)。
