feat(ui): settings panel IA, blocklist search/filter, undo window and recent actions (v0.60.0)

Settings panel regrouped into five navigable sections (blocking & list /
rules / backup & sync / update & about / logs-diagnostics last) with anchor
navigation. Blocklist gains live search, platform filter and a visible
count. Undo toast duration is now configurable (undoToastSeconds, default
10s, clamped 5-30). A new RecentActions module (own GM key, capped ring of
20, excluded from sync/export) records manually confirmed local blocks and
surfaces a per-entry undo list in the panel. Key paths (sign out, clear
logs, restore snapshot, import) now use the in-house confirm modal instead
of window.confirm; the AI Key prompt stays native deliberately.

Bilibili/Douyin blocking semantics unchanged; keyword auto-rule hits
deliberately not recorded in recent actions (undo would be immediately
re-blocked) - documented in panel text and changelog.
