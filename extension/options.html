扩展设置

电脑和支持扩展的平板使用同一份 MV3 构建。API Key 只保存在当前设备；同步服务只接收客户端加密后的文档。

设备直连 API

这是 AI 的第二种方式。保存成功后会同时启用 direct；请求由扩展 service worker 发出，页面脚本和同步包都看不到 Key。地址必须是 HTTPS；本机测试才允许 loopback HTTP。

数据导入 / 导出

可导入旧 Tampermonkey 的 OmniBlock JSON，也可导入本扩展导出的完整包。导入前会先保存一次本机回滚点，不包含 API Key、登录令牌、事件日志或本地快照。


      

        
        
      

      

        
      

      

    


    

      
账户级加密同步

      
同步前在每台设备上使用同一个账户和同步口令。账户密码用于登录，独立同步口令用于客户端 AES-GCM 加密；服务器看不到名单、规则、反馈和 API Key。当前按钮执行“本机与云端合并后写回”，遇到并发 revision 冲突会自动重试。
