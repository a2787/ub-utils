# OmniBlock 拉黑不上限

一份名单，跨 **B站 / 微博 / 知乎 / 百度贴吧 / X(Twitter) / 抖音** 六个平台，在**你自己的浏览器里**本地屏蔽指定用户的所有内容（评论、帖子、动态、视频、弹幕…）。

- 没有数量上限（名单存在你电脑上，几万条无压力）
- 跨平台（一个名字，六处通用）
- 全程本地，不联网、不上传任何数据
- 不调用平台官方拉黑接口（不会污染你的推荐模型）

> 形态：Tampermonkey 用户脚本（单文件 `omniblock.user.js`）。基于 Pynseq 思路，MIT 许可。

---

## 安装（两步，一次性的）

1. 装 **Tampermonkey** 浏览器插件（Chrome / Edge / 火狐都行）：
   打开应用店搜 "Tampermonkey" 安装即可。装完它会在浏览器右上角多一个图标，之后就不用管了。
2. 装本脚本：
   - 方式一：把 `omniblock.user.js` 直接**拖进浏览器窗口**，Tampermonkey 会弹出安装确认 → 点「安装」。
   - 方式二：Tampermonkey 图标 → 「管理面板」→ 右上「实用工具」→「导入」→ 选 `omniblock.user.js`。

装好后，打开上面任意平台网页即可生效。

---

## 使用

- **打开设置面板**：浏览器右上角 Tampermonkey 图标 → 「OmniBlock 设置」；或直接按脚本菜单。
- **加人**：设置面板里点「添加」→ 选平台 → 填用户标识（uid / sec_uid / handle 等）→ 填备注名 → 确定。
- **删人 / 看名单**：设置面板里逐条「删」。
- **备份 / 恢复**：「导出」生成 `omniblock-backup-日期.json`；「导入」选这个文件即可还原。**清浏览器数据或卸脚本前务必先导出。**
