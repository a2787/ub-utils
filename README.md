# OmniBlock 拉黑不上限（6 平台统一黑名单 / Tampermonkey 用户脚本）

这是一个浏览器用户脚本：**一份名单，在 6 个平台已适配的内容条目中隐藏指定用户**。
电脑和支持 Tampermonkey 的平板 Edge 使用同一个 `omniblock.user.js`；名单与浏览数据默认保存在各自设备
的 Tampermonkey GM 存储中。

支持平台：**B站 · 微博 · 知乎 · 百度贴吧 · X(Twitter) · 抖音**（不含小红书）。

> **名称映射**：Tampermonkey 管理面板里脚本名显示为「本地内容过滤增强」，这就是 OmniBlock；菜单命令为
> 「OmniBlock 设置」。脚本名刻意低调，不是另一个脚本。

---

## 安装（傻瓜版）

1. 给浏览器装一个 **Tampermonkey**（油猴）插件：Chrome / Edge 扩展商店搜 "Tampermonkey" 安装，
   装好一次之后基本可以忘掉它。
2. 把本项目的 `omniblock.user.js` 导入 Tampermonkey：管理面板 →「实用工具」→「导入」→ 选
   `omniblock.user.js`；或复制文件内容，新建脚本粘贴保存。
3. 进任意支持的平台：点页面右下角常驻的 **⚙ 按钮**直接打开设置（默认半透明，悬停或键盘聚焦后展开控制
   坞），或在 Tampermonkey 右上角图标 →「OmniBlock 设置」管理名单、导出备份。改一行刷新页面即生效，
   调试最直观；也可发布到 GreasyFork 分享给别人。

桌面和目标平板使用同一份脚本，不需要安装独立浏览器扩展：电脑端继续在 Tampermonkey 中更新脚本，平板
Edge 安装 Tampermonkey 后导入同一份脚本或打开更新地址即可。当前版本已为窄屏和触控调整设置面板、内容
入口、AI 审核浮层、关闭按钮与表单布局；本仓库的 390px 触控夹具只证明代码路径，尚未代替目标平板的实际
安装验证，因此平板实机状态仍记为 `blocked`（已封存待重启，见维护文档）。

## 第一次屏蔽与撤销

- 打开平台自己的菜单（三点或「更多」→「举报」「加入黑名单」），旁边会多出 **「🚫 本地拉黑」**；点它即本地生效，
  默认不再弹二次确认。帖子/视频作者旁也会出现「本地拉黑作者」，点击同样直接生效。脚本自动从页面解析规范身份，
  不用手填（B站评论/动态在 Shadow DOM 内已做穿透，同样可用）。
- 屏蔽后评论和弹幕无提示、零占位消失，不显示恢复条、不留空行；帖子、动态、搜索卡等其他内容按设置折叠成
  灰条（默认，可追溯）或完全消失。撤销 toast 默认停留 10 秒（可在设置调 5–30 秒）；设置面板
  「最近本地屏蔽操作」最多 20 条，每条都可再撤销；也可用菜单「撤销上一次本地屏蔽」。
- 想恢复二次确认：在设置关闭「快捷/作者入口直接屏蔽」。批量、弹幕和 UID 候选始终保留确认。
- 只有能从条目自身可靠解析出规范身份时，脚本才会隐藏内容或提供可执行的拉黑入口；解析不到就保持原样。
  各平台评论、帖子、回答/文章、搜索结果和作品列表的实际覆盖，以
  [平台适配细节](docs/usage/PLATFORMS.md) 的验证表和 [当前维护状态](docs/maintenance/CURRENT.md)
  的证据标签为准。
- 设置面板也可手动按平台 + 身份值添加、删除、导出/导入 JSON 备份。手动添加和导入走同一套身份规范化：
  数字 UID 去掉无意义前导零，X handle 去掉 `@` 并转小写，未知身份前缀跳过，备注按纯文本显示；各平台
  该填哪种身份值见 [平台适配细节 · 身份填写表](docs/usage/PLATFORMS.md)。
- 设置面板按「屏蔽与名单 / 规则 / 备份与同步 / 更新与关于 / 日志诊断」五个分组排列，顶部有分组导航；
  脚本自建界面（面板、弹窗、审核浮层、确认气泡、toast）配色自动跟随系统深色模式，无独立开关，也不改动
  平台页面自身配色。设置面板顶部和右下角齿轮显示当前实际运行的「版本」与「构建」，便于确认刷新后不是
  旧脚本残留。

## 数据在哪

- 名单、设置和浏览数据默认只保存在当前设备的 Tampermonkey GM 存储中；脚本在独立本地存储键自动保留最近
  5 份名单快照（可关闭、可恢复上一份）。快照只用于误删、错误导入或主名单键损坏后的回退，浏览器配置整体
  丢失时仍应把 JSON 导出到下载目录或其他设备。
- 账户级客户端加密同步（可选）：名单/可同步设置/提示词个性化加密后同步，API Key、口令、日志和备份
  不进同步包。存储降级、同步部署和本地诊断的完整说明见
  [AI、规则与同步](docs/usage/AI-AND-SYNC.md)。

## 隐私边界

- **绝不写平台**：所有拉黑都是本地名单 + 自建 UI，不触发平台举报、官方拉黑、「不感兴趣」、关注或发帖，
  不污染推荐模型；右键完全交还页面（脚本不注册 `contextmenu` 监听）。
- **AI 只发你主动触发的内容**：AI 关闭时不发送页面内容；启用后默认仅手动分析——只有点击「分析本页」才
  会把当前页已观察、截断后的作品内容、评论、弹幕或帖子正文发送到你直接填写的 OpenAI-compatible API；
  页面加载和滚动不会自动请求。自动模式、缓存与批量上限等边界见
  [AI、规则与同步](docs/usage/AI-AND-SYNC.md)。AI 结果必须经人工审核才写入名单。
- **按需匿名请求**：B站弹幕工具只有在你主动点 `UID?` 或实际执行某条/某批弹幕屏蔽时，才按需匿名请求
  B站用户卡片接口校验数字候选；页面初始加载不会逐一反查全部弹幕 hash。主动点击「检查更新」时会请求
  GitHub；Tampermonkey 自身的例行更新请求取决于它的更新设置。
- **Key 只在本机**：API Key 只保存在当前设备，账户同步不会上传它。
- 脚本不向页面暴露任何可写接口：设置、名单和 AI/同步句柄只在脚本内部可见，页面脚本无法读取、修改或借
  它们外传数据；页面上只有只读的版本/构建标识。

## 更新方法

1. **一键检查更新**：设置面板（或 Tampermonkey 菜单）点「检查更新」，自动比对仓库版本；有新版会弹出
   Tampermonkey 的「更新」页，点一次「更新」即装好（用户脚本无法在运行时自替换）。
2. **全自动**：在 Tampermonkey 里把本脚本「更新 → 模式」设为「自动」，之后例行检查时静默应用新版。
3. **手动覆盖**：把新文件再拖进 Tampermonkey 一次，版本号更高会弹「更新吗」；名单和设置不会丢。
